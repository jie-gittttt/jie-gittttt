# Jeffrey

I'm a Data Science student interested in machine learning and AI systems, combining model research, empirical evaluation, and practical engineering. My projects explore state space models, diffusion, retrieval-augmented generation, and parallel computing.

## Core Research & Engineering Areas

- Machine learning and deep learning
- Generative modeling and efficient model architectures
- Retrieval-augmented language systems
- Probabilistic modeling and time-series analysis
- Parallel and heterogeneous computing

## Projects

| Repository | Description |
| --- | --- |
| [usm-mss-diffusion](https://github.com/jie-gittttt/usm-mss-diffusion) | Studies U-Shape Mamba for diffusion models and introduces MSSBlock, a layer-level CNN–SSM fusion module. Includes ablations, training and evaluation code, experiment logs, figures, and a paper. |

## 项目及简介

| 仓库 | 简介 |
| --- | --- |
| [usm-mss-diffusion](https://github.com/jie-gittttt/usm-mss-diffusion) | 研究 U-Shape Mamba 在扩散模型中的应用，并提出逐层 CNN–SSM 融合模块 MSSBlock。仓库包含消融实验、训练与评测代码、实验日志、图表和论文。 |
| [multi-agent-rag-robustness-eval](https://github.com/jie-gittttt/multi-agent-rag-robustness-eval) | 多智能体 RAG 评测流程，通过对抗查询和上下文测试 RAG 系统，对比干净输入与扰动输入的表现，并生成鲁棒性报告。 |

| [mamba-image-super-resolution](https://github.com/jie-gittttt/mamba-image-super-resolution) | 复现 MambaIR 与 MaIR 图像超分辨率模型，分析扫描方向的影响，并评估 CNN–SSM 融合模块。 |
| [adaptive-gpr-stock-forecasting](https://github.com/jie-gittttt/adaptive-gpr-stock-forecasting) | 比较多种高斯过程回归股票预测策略，并在不同市场状态下评估基于波动率的自适应窗口方法。 |
| [parallel-computing](https://github.com/jie-gittttt/parallel-computing) | 涵盖 MPI、Pthread、OpenMP 和 CUDA 的并行计算项目，包含性能对比、实验材料和交互式原理演示。 |
